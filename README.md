# Switchboard

Ops console for the scam-call honeypot. This repo currently ships the human operations dashboard. It reads mock fixtures through a small data port so a backend can be attached later without rewriting the screens.

## Run the dashboard

From `apps/dashboard`:

```bash
npm install
npm run dev
```

Open `http://localhost:5173`. The app redirects to `/dashboard/live`.

Other commands, from the same directory:

```bash
npm run typecheck
npm run check:fixtures
npm run build
npm run preview
```

From the repo root, `npm run dev`, `npm run typecheck`, and `npm run build` forward to the dashboard app. Install dependencies in `apps/dashboard` first.

## Routes

- `/dashboard/live` — active calls, elapsed time, conversation state, transcript, extracted intelligence, pipeline latency
- `/dashboard/calls` — call history
- `/dashboard/calls/:id` — timeline, transcript, state transitions, observations, correlation, technical events
- `/dashboard/campaigns` — campaign list
- `/dashboard/campaigns/:id` — timeline, related calls, script phrases, shared indicators, similarity, hourly activity
- `/dashboard/system` — provider status, latency, concurrency, cost, errors

## Mock data

Fixtures live in `apps/dashboard/src/mocks/` and are generated by `apps/dashboard/scripts/generate-fixtures.mjs`. Regenerate with `npm run generate:fixtures` inside `apps/dashboard`.

Screens talk only to `OpsDataPort` (`apps/dashboard/src/data/port.ts`). The current binding is the mock adapter, set in `apps/dashboard/src/data/client.ts`. Replacing that one export is the switch to HTTP or WebSocket.

The shapes the UI expects are listed in `docs/FRONTEND_DATA_REQUIREMENTS.md`.

## Provenance

Intelligence is marked **Observed**, **Inferred**, or **Unverified**. Raw captures and derived interpretations are separate marks, and structured observations keep the raw text and the interpretation in different columns.
